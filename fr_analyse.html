PALS

Nous allons faire une première analyse avec les scripts PALS récupérés dans dépôt Git de M. Dupont.

Après consultation de la documentation, et du fichier d'exercice pals. Nous faisons un prétraitement pour que les scripts PALS puissent traiter les textes donnés.

Nous lançons le script cooccurrents.py avec la commande ci-contre. Nous ciblons la recherche sur nuage et ses dérivés avec l'utilisation d'une expression régulière.

Après avoir lancée une première fois le script, nous voyons dans le résultat des problèmes d'encodage mal nettoyé malgrès le fichier converti en UTF-8. Ansi, pour avoir un résultat plus parlant, nous avons écrit un script python* qui tente de corriger les erreurs d'encodage du à la reconversion.

Le résultat se trouve dans le bouton "Dumps-cooccurents"

* (click to show the code)


                        
                    

                


                
                

                    # Prétraitement des problèmes d'encodages
                    python fix_encoding.py contextes-fr.txt contextes-fr-clean.txt
                    python fix_encoding.py dumps-text-fr.txt dumps-text-fr-clean.txt

                    # Cooccurrences des fichiers dumps-text
                    python cooccurrents.py ../dumps-text-fr-clean.txt --target "(N|n)uage(s|ux|use|uses)?" --match-mode regex > ../result/francais/dumps-cooccurents.tsv 2> /dev/null 
                    
                    # Cooccurrences des fichiers contextes
                    python cooccurrents.py ../contextes-fr-clean.txt --target "(N|n)uage(s|ux|use|uses)?" --match-mode regex > ../result/francais/contextes-cooccurents.tsv 2> /dev/null

Analyse

                        
Dumps - Cooccurrences

                        

                            
    
                                
  • Les problèmes d'encodage ont quasiment disparu, il reste quelque artefacts du aux dumps des sites webs.
    • 
                                
  • Deux champs lexicaux dominent : scientifique et environnement
    • 
                                
  • 
                                    Le mot nuage apparaît souvent avec mot et informatique. 
                                    
         
                                    La paire mot/nuage peut être interprété par des métadiscours, explication du mot ou encore pour l'expression 'nuage de mot' qui faisait partie de nos centres de recherche.
                                    
         
                                    Le terme informatique semble être LE thème principal de tous nos corpus avec une spécificité de près de 80%, ce qui est énorme.
                                
    • 
                                
  • 
                                    Le mot que nous avons à la suite sont surtout présent pour la structure, avec une majeure partie de termes masculin
                                    ce qui est explicable, car le mot "nuage" est au masculin.
                                
    • 
                                
  • 
                                    Un peu plus loin dans le tableau, nous retrouvons des termes plutôt présent dans des corpus sur l'environnement, comme pesticide,
                                     ciel, Météorologie...
                                
    • 
                                
  • Les mots comme url sont très présents et haut dans le tableau. Ce sont des restes d'extractions dumps des liens.
    • 
                            

                        

                        
Contextes - Cooccurrences

                        

                            
    
                                
  • 
                                    Tous comme le tableau Dumps, les deux premiers mots trouvés sont informatique et mots,
                                    la différence est l'ordre dans le tableau. Pour contextes, informatique passe avant mots.
                                
    • 
                                
  • Les mots de structure sont moins présents.
    • 
                                
  • Le domaine informatique ressort davantage, les termes en lien avec l'environnement viennent surtout après les lignes 25.
    • 
                                
  • Les données de fréquence et de spécificité diffèrent grandement des cooccurrences des corpus dumps. Le plafond de spécificité pour 
                                    le corpus contextes n'atteint que 20.83 alors que dans dumps le maximum monte à 99.71. Un différence flagrande.
