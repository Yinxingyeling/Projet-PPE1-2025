Visualisation des résultats de l'analyse de texte à l'aide de nuages de mots

Sommaire
    4 mai 2023

    Les connaissances fondées sur l'IA commencent par de meilleures données. Chez insightsoftware, nous connectons, gérons et visualisons vos données, transformant les informations brutes en réponses qui poussent à l'action.

    ChatGPT Claude Mode Google AI Grok Perplexity

    Qu'est-ce que l'analyse de la fréquence des mots ?

    L'analyse de la fréquence des mots est une technique utilisée pour analyser la fréquence des mots dans un texte ou un ensemble de textes. En comptant la fréquence d'apparition de chaque mot, cette méthode permet d'identifier les termes les plus couramment utilisés, ce qui peut révéler des schémas, des thèmes ou des sujets importants. Elle est largement utilisée dans des domaines tels que la linguistique, l'analyse de contenu et le référencement pour comprendre l'utilisation de la langue, suivre les tendances ou optimiser le contenu. L'analyse de la fréquence des mots permet de résumer de grands volumes de texte et de découvrir des informations sur le langage ou les styles de communication.

    Utilisation du nuage de mots pour l'analyse de la fréquence des mots

    Un nuage de mots ou nuage de tags est une représentation visuelle de données textuelles sous forme de tags, qui sont généralement des mots uniques dont l'importance est visualisée par leur taille et leur couleur. Alors que les données non structurées sous forme de texte continuent de connaître une croissance sans précédent, en particulier dans le domaine des médias sociaux, il est de plus en plus nécessaire d'analyser les quantités massives de texte générées par ces systèmes. Un nuage de mots est une excellente option pour aider à interpréter visuellement un texte et est utile pour obtenir rapidement un aperçu des éléments les plus importants dans un texte donné, en visualisant la fréquence des mots dans le texte sous la forme d'une liste pondérée.

    Depuis la version 5.0.1, Dundas BI vous permet de visualiser les données à l'aide de la visualisation native Word Cloud qui affiche le texte en couleur et en taille.

    Ce blog démontrera comment créer un nuage de mots dans Dundas BI en utilisant la bibliothèque D3.js. Notez que cela n'est pas nécessaire si la visualisation native du nuage de mots est utilisée à partir de la version 5.0.1, car elle peut maintenant être créée en quelques clics.

    Dans cet exemple, nous utiliserons des données de vente au détail stockées dans une base de données SQL et nous analyserons ce que les clients ont à dire sur un magasin particulier. Vous pouvez appliquer le même processus pour analyser des données provenant de n'importe quelle autre source, comme Twitter, Facebook, etc.

    Étapes de l'analyse de la fréquence des mots

    La première étape de la visualisation des données sous forme de nuage de mots consiste à analyser le texte et à extraire la fréquence de chaque mot dans le texte. Dans notre exemple, les avis des clients sont stockés dans une colonne d'une table SQL et un algorithme d'exploration de texte est exécuté sur cette colonne pour obtenir la fréquence des mots.

    Cube de données

    Pour ce faire, il faut d'abord créer un cube de données et supprimer la table qui contient la colonne de texte. Dans notre cas, le texte est stocké dans une table SQL appelée [dbo][Commentaires]. Le cube de données et le résultat ressemblent à ceci :

    Figure 2 : Créer le cube de données

    Figure 3 : Aperçu des données

    Ensuite, déposez la transformation d'analyse du langage R qui vous permettra de mettre en œuvre l'exploration de texte en utilisant le langage R. Si vous n'avez jamais utilisé la transformation R Language Analysis, vous pouvez commencer ici.

    Figure 4 : Ajouter la transformation R

    Configurez la transformation R Language Analysis et ajoutez un espace réservé pour la colonne de texte. Dans ce cas, la colonne de texte est appelée "Commentaire" et un espace réservé "texte" est défini pour elle. Ce caractère générique sera utilisé dans l'algorithme d'exploration de texte ci-dessous.

    Figure 5 : Ajouter l'espace réservé pour la colonne de texte

    Une fois que le placeholder est prêt, ajoutez le script R ci-dessous dans la section "Edit Script". Le script utilise la bibliothèque d'exploration de texte appelée tm(cliquez ici pour plus de détails sur le paquetage tm) pour calculer la fréquence des mots présents dans le texte et affiche le mot et sa fréquence. En d'autres termes, il détermine le nombre de fois que le mot apparaît dans le texte :

    bibliothèque(tm) ;

    review_text <- paste($text$, collapse=” “);

    review_source <- VectorSource(review_text);

    corpus <- Corpus(review_source);

    corpus <- tm_map(corpus, removePunctuation);

    corpus <- tm_map(corpus, stripWhitespace);

    corpus <- tm_map(corpus, removeWords, stopwords(“english”));

    dtm <- DocumentTermMatrix(corpus);

    dtm2 <- as.matrix(dtm);

    frequency <- colSums(dtm2);

    frequency <- sort(frequency, decreasing=TRUE);

    frequency <- head(frequency, 50);

    output <- data.frame(names(frequency), frequency);

    Figure 6 : Résultat de la fréquence des mots

    Notez que cet algorithme ne se contente pas de compter le nombre de fois qu'un mot apparaît dans le texte (dans ce cas, tous les commentaires des clients). Il effectuera également les préparations de données nécessaires, telles que la suppression de la ponctuation, des espaces et des mots vides (mots couramment utilisés, tels que "le", que nous ne voulons pas compter).

    En conséquence, il renverra les 50 mots les plus fréquents dans le texte.

    Création du nuage de mots

    Créer un tableau

    Sur le canevas du tableau de bord, créez un tableau de visualisation à partir du cube de données ci-dessus qui sera utilisé pour alimenter le nuage de mots.

    Figure 7 : Création d'un tableau dans le tableau de bord

    Le nom de script du tableau (trouvé dans ses propriétés) sera utilisé dans le script du nuage de mots dans la section suivante. Renommez ce nom de script si nécessaire

    Figure 8 : Notez le nom du script de la table

    Créer le nuage de mots

    Pour créer le nuage de mots, nous utiliserons la bibliothèque D3.js et ferons référence à l'exemple présenté ici :

    https://github.com/jasondavies/d3-cloud

    Dans l'événement Ready du tableau de bord, ajoutez le script D3.js pour créer le nuage de mots.

    Figure 9 : Ajouter le script dans l'événement Ready du tableau de bord

    Figure 10 : Script de création du nuage de mots

    Afficher les données dans le nuage de mots

    Pour afficher les données sur le nuage de mots, nous utiliserons un composant d'étiquette HTML qui servira de conteneur pour le nuage et nous permettra de positionner et de redimensionner le nuage en fonction des besoins sur la toile du tableau de bord.

    Pour ajouter l'étiquette au canevas du tableau de bord, développez la section Composants dans la barre d'outils et déposez l'étiquette HTML sur le canevas.

    Figure 11 : Ajouter l'étiquette HTML

     

    Go to the Text properties and set the HTML label text property to <div></div>

    Figure 12 : Définir le texte de l'étiquette HTML

    Ajoutez maintenant un autre script dans l'action Ready du tableau de bord qui lit les données du tableau créé précédemment, les lie au nuage de mots et les affiche dans le conteneur d'étiquettes HTML. Pour s'assurer que le nuage de mots change lorsque les données sont modifiées dans le tableau, par exemple en cas de changement de filtre, etc., ajoutez également ce script dans l'action Données modifiées du tableau.

    Dans ce script, le tableau est référencé comme frequencyTable, et l'étiquette HTML est référencée comme wordcloudContainer. Assurez-vous que les noms de script du tableau et des contrôles de l'étiquette HTML sur votre tableau de bord correspondent aux noms dans le script :

    // get the html label that will display the word cloud

    var placeholderElement = document.getElementById('wordcloudContainer') ;

     

    //get the data result from the frequencyTable

    var data = frequencyTable.metricSetBindings[0].dataResult ;

     

    // disable paging to make sure the datapoints displayed are not limited due to it

    data.request.pagingOptions.pagingKind = 'None' ;

     

    //store the words and their frequencies as an array

    var frequency_list = [] ;

    for (i = 0;i<data.cellset.cells[0].length;i++)

    {

    var text = data.cellset.rows[i].members[0].caption ;

    var value = data.cellset.cells[0][i].value ;

    valeur = valeur * 10 ;

    frequency_list.push({“text” : text, “size” : value});

    }

     

    //define the color scheme to be used

    var color = d3.scale.linear()

    .domain([0,1,2,3,4,5,6,10,15,20,100])

    //.range([“#ddd”, “#ccc”, “#bbb”, “#aaa”, “#999”, “#888”, “#777”, “#666”, “#555”, “#444”, “#333”, “#222”]);

    .range(["#000000", "#000000", "#000000", "#000000", "#000000", "#000000", "#000000", "#000000", "#000000", "#000000", "#333", "#222"]) ;

     

    d3.layout.cloud().size([500,500])

    .words(frequency_list)

    .rotate(0)

    .fontSize(function(d) { return d.size; })

    .on("end", draw)

    .start() ;

     

    //draw the words on the html label

    function draw(words) {

    d3.select(placeholderElement).append("svg")

    .attr("width", 500)

    .attr("height", 500)

    .attr("class", "wordcloud")

    .append("g")

     

    // without the transform, words would get cutoff to the left and top, they would appear outside of the SVG area

    .attr("transform", "translate(320,200)")

    .attr("transform", "translate(140,125)")

    .selectAll("texte")

    .data(words)

    .enter().append("text")

    .style(“font-size”, function(d) { return d.size + “px”; })

    .style(“fill”, function(d, i) { return color(i); })

    .attr("transform", function(d) {

    return "translate(" + [d.x, d.y] + ")rotate(" + d.rotate + ")" ;

    })

    .text(function(d) { return d.text; });

    }

    Résumé

    Comme vous pouvez le constater, un nuage de mots permet d'analyser rapidement n'importe quel texte et fournit des informations précieuses sur des sujets essentiels. L'exemple ci-dessus montre comment créer un nuage de mots rudimentaire dans Dundas BI. Vous pouvez modifier et renforcer l'apparence du nuage de mots en ajustant son script, et en ajoutant des améliorations supplémentaires telles que différents schémas de couleurs, qui peuvent être affichés en fonction de la fréquence des mots sélectionnés.

    Le nuage de mots est une excellente visualisation qui permet de mettre rapidement en évidence les mots clés d'un texte, mais il ne permet pas d'effectuer une analyse précise, ce qui est souvent l'objectif de l'analyse de texte dans un contexte professionnel.

    Pour combler cette lacune et fournir à la fois le premier aperçu rapide obtenu en jetant un coup d'œil au nuage de mots et la vue précise nécessaire à l'analyse commerciale, nous recommandons de superposer le nuage de mots à un diagramme à barres montrant le même résultat. Voici un exemple de ce que cela donne sur un tableau de bord :

    Figure 14 : Nuage de mots superposé à un diagramme à barres
