    云 - 它是什么？

    云是用户和企业可存储其文件和应用程序的庞大的联机存储空间，可通过 Internet 连接从任何位置访问。云还提供计算能力、数据库、网络和软件应用程序等服务。

    云的主要用途是通过 Internet 提供对计算资源和服务的按需访问。这包括各种服务，例如服务器、存储、数据库、网络、软件、分析和智能。用户和组织能够通过云使用这些资源，而无需管理物理服务器或在其自己的计算机上运行软件应用程序。

    关键要点

    云和 Internet

    云和 Internet 是可协同工作的不同技术。Internet 是全球连接设备的底层基础结构，云使用此基础结构来提供服务和资源。

    数据中心

    在云中存储数据或运行应用程序时，你使用的是位于数据中心的远程服务器。数据中心位于世界各地，并由云服务提供商运营。

    云的类型

    云具有不同类型，包括个人云、商业云、公有云、私有云和混合云。

    对生活和工作的影响

    通过支持不同领域轻松访问信息和服务（包括个人使用、商业、教育和政府），云为我们的生活和工作方式提供了便利。

    常见用例

    常见的云用例包括云存储、流式处理服务、社交媒体平台、基于云的安全解决方案、聊天机器人等 AI 支持的解决方案，以及适用于个人和企业的基于云的综合性服务产品（如 Microsoft Cloud）。

    未来趋势

    AI 集成、边缘计算和量子计算有望塑造云计算的未来。云将继续对教育、医疗保健、环境可持续性和经济增长产生积极影响。

    什么是云

    云的工作原理

    在科技方面，云是什么？

    在技术方面，云是远程服务器的全球网络，旨在存储和处理其他设备和计算机的数据。通过此体系结构，用户可以将其文件和应用程序保存在云中。他们可以联机访问它们，而不必依赖于本地存储。

    云提供一套全面的服务，包括服务器、存储、数据库、网络、软件、分析和智能。个人和组织可以使用这些服务，而无需管理物理服务器或在其自己的计算机上运行软件应用程序。这带来了显著的优势，例如能够根据需求缩放资源、改进协作以及最大程度地降低与维护物理基础结构相关的成本。

    云的历史和发展

    云计算的起源可以追溯到计算技术的早期，当时使用大型计算机为多个用户处理数据。20 世纪 60 年代，出现了"分时"这一概念，多个用户因此可以同时访问同一计算机。通过引入在多个用户之间共享资源的理念，此方法奠定了现代云计算的基础。

    Internet 则在云计算的兴起中发挥了关键作用。20 世纪 90 年代，Internet 的广泛采用使得从世界任何地方访问数据和应用程序成为可能。这促成了基于云的服务的发展，例如电子邮件、文件存储和软件应用程序。 

    如今，云已成为日常生活中必不可少的部分。人们使用它来存储照片、音乐和文档、访问电子邮件和社交媒体帐户，以及运营企业。通过帮助提高企业的灵活性、效率以及成本效益，云还改变了企业的运营方式。

    云和 Internet

    云和 Internet 是协同工作的不同技术。Internet 是全球互连计算机网络，它支持设备交换数据和通信，并为网站和电子邮件等服务提供支持。

    相比之下，云指的是通过 Internet 提供存储、计算能力和应用程序的服务。用户无需将数据保留在本地设备上，而是将其数据和应用程序存储在云中并进行访问。

    从本质上讲，Internet 是连接全球设备的基础性基础结构，而云使用此基础结构来提供各种服务和资源。

    数据中心的角色

    那么，云在哪里？ 它位于遍布全球的数据中心。

    在云中存储数据或运行应用程序涉及使用存放在数据中心的远程服务器。这些云基础结构设施是高度安全的，并且配备了必要的硬件和软件来确保数据处于安全状态且易于访问。云服务提供商（如 Microsoft Azure）可在世界各地运营许多数据中心，以支持各种服务。

    从云访问数据时，设备会向云服务提供商的服务器发送请求。然后，云服务器会检索数据并将其发送回设备。这一过程的发生速度极快，就像数据存储在你自己的计算机上一样。

    数据中心在全球范围内进行战略性分布，以实现低延迟和高可用性。这意味着无论你身在何处，都可以轻松、快速且可靠地访问数据。 

    云的类型

    那么简单来说，云是什么？ 这不是一个容易回答的问题，因为存在不同类型的云。具体包括：
     
    • 个人云是个人解决方案，支持你通过 Internet 远程存储、访问和管理数据。这些解决方案通常使用个人硬件，例如家用服务器或专用的云服务。个人云提供了云存储的便利性，同时由于个人所有提供了更高的控制和安全性。
    • 商业云是公司向企业和个人提供的云计算服务。它们通过 Internet 提供对计算资源、存储和应用程序的可缩放和按需访问。这些服务通常由大型云服务提供商管理，可提供高可用性、增强的安全性和优化的性能。组织还可能采用多云方法，以使用多个云服务提供商来避免供应商锁定并增强冗余。
    • 公有云通过 Internet 提供计算服务，以向公众提供存储和应用程序等资源。它们通常由大型云服务提供商管理。
    • 私有云是专用于单个组织的云计算环境。它们提供增强的控制、安全性和自定义。私有云可以托管在本地，也可以由云服务提供商托管。
    • 混合云将私有云和公有云环境组合在一起，并在它们之间共享数据和应用程序。利用此设置，组织可以在本地维护一些数据和应用程序，并利用公有云的可伸缩性和灵活性。利用混合云，组织还可以改进其现有基础结构，同时满足安全性和合规性要求。此外，云迁移策略和工具支持根据需要将数据和应用程序从本地无缝传输到云。

    云服务类型

    云服务提供不同级别的云计算资源，可提供满足各种需求的灵活性和可伸缩性。云服务包括以下三种主要类型：
     
    • 基础结构即服务 (IaaS) 通过 Internet 提供虚拟化计算资源，例如虚拟机、存储和网络。
    • 平台即服务 (PaaS) 为开发人员提供了用于生成、部署和管理应用程序的框架。PaaS 在最大程度上减少了对开发人员管理底层基础结构的需求，为其提供更多时间来专注于构建高质量的应用。
    • 软件即服务 (SaaS) 通过 Internet 向支付软件费用的订阅者提供应用程序。借助 SaaS，个人和组织可以访问和使用软件，而无需管理硬件或基础结构。SaaS 还通过消除对本地安装和维护的需求降低了成本。

    优势

    云的优势

    通过提高信息与服务的可访问性和便利性，云改变了日常生活：
     
    • 个人方面。云存储服务提供从任何设备通过 Internet 连接轻松访问文件的功能。借助此功能，你可以在家庭计算机上启动文档，在上下班途中在手机上继续处理，然后在办公室计算机上完成它。此外，使用基于云的应用程序（如电子邮件和社交媒体平台），可以轻松地与家人及好友通信和共享，而无论他们身处何处。
    • 企业方面。无论规模大小，各种公司都从云服务中获得了显著收益。通过云计算，组织可以扩展其运营，而无需在硬件方面进行重大前期投资。Azure 等服务为企业提供了按需扩展其计算资源的灵活性，且只需为所使用的资源付费。这种可伸缩性对于需要谨慎管理成本的初创企业和小型企业尤其有用。此外，基于云的工具（如 Microsoft Teams）可通过支持团队成员之间实现实时通信和协作来提高工作效率，而无需考虑其物理位置。
    • 教育方面。在教育领域中，云改变了学生和教师访问和共享信息的方式。使用在线学习平台，学生可以从任何位置访问课程资料、提交作业和接收反馈。这一点在 COVID-19 疫情期间尤为重要，它支持在学校关闭期间仍然能够继续开展教育活动。此外，基于云的研究工具和数据库提供对各种信息和资源的访问权限，从而提供了学习和研究的效率和有效性。
    • 政府方面。政府机构采用了云技术来改进服务并简化运营。迁移到云有助于政府提高公共服务的效率和可访问性。例如，基于云的系统简化了税务申报、许可续订和公共记录管理等流程，提高了这些服务的易用性并减轻了管理工作量。此外，云计算改进了政府部门和机构之间的数据共享和协作，从而提高了公共服务交付的协调性和有效性。
    总的来说，云能够在数秒内从世界上几乎任何位置提供信息和服务，这极大地影响了生活的方方面面。无论是与所爱的人保持联系、管理企业、从事教育活动还是访问政府服务，云都提供了可提高这些活动的效率和便利性的基础结构。这种广泛的可访问性和易用性是云技术不断发展和演变的主要原因，它塑造了世界各地的人们的生活和工作方式。

    用例

    云技术的实际应用

    在日常生活和企业运营的各个方面，云已经成为不可或缺的一部分，并有多个用例和示例突出显示了它的多功能性和优势。

    云存储

    云计算的一个突出用例是云存储。借助 SharePoint 等服务，用户能够从任何位置存储、访问和共享文件。通过支持多人同时处理同一文档以确保每个人都可以访问最新信息，这些平台促进了协作。对于企业而言，这意味着提高运营效率和简化工作流，因为员工无需使用物理存储或复杂的文件传输方法即可轻松共享和检索文档。

    流式处理服务

    Netflix、Spotify 和 Xbox Cloud Gaming 等流式处理服务在很大程度上依赖于云技术向全球数百万客户提供内容。通过在云中存储海量电影、电视节目和音乐库，这些服务通过无缝且不间断的客户体验提供对内容的按需访问。借助云基础结构的可伸缩性，这些平台能够处理大量数据和客户请求，即使在高峰使用时段仍保持高性能。此功能可提高客户满意度，并支持这些服务的增长和将其扩展到新市场。

    社交媒体平台

    Facebook 和 WhatsApp 等社交媒体平台使用云计算来管理和处理其用户生成的海量数据。通过使用云，这些平台能够安全地存储用户数据、提供实时更新和支持消息传递、视频通话与内容共享等功能。云技术可帮助社交媒体公司确保其服务可靠、可缩放且能够处理其用户群的动态需求。这种连接可促进全球沟通和社交互动，从而支持用户与朋友和家人保持联系，而无需考虑地理障碍。

    安全性

    在安全领域，基于云的解决方案（如 Microsoft Defender for Cloud）可针对网络威胁提供可靠的保护。这些服务使用高级算法和机器学习来实时检测和响应潜在的安全漏洞。通过持续更新其威胁数据库和安全协议，基于云的安全解决方案可提供比传统本地系统更有效的保护。借助基于云的安全性，个人和企业均可保护其数据并维护其数字环境的完整性。

    AI 应用程序

    AI 应用程序（包括聊天机器人和虚拟助手）也依赖于云技术。Azure AI 等服务提供开发和部署复杂 AI 模型所需的计算能力和数据存储。这些 AI 驱动的解决方案可改进客户服务、自动执行日常任务，并提供个性化的客户体验。例如，聊天机器人可处理客户查询，从而支持客户服务代理专注于更复杂的问题。此外，虚拟助理可帮助用户管理其日程安排、设置提醒以及通过语音命令执行各种任务。

    Microsoft Cloud

    受信任的 Microsoft Cloud 通过其广泛的产品和服务展示了云技术的强大功能和多功能性：
     
    • 企业方面。Azure 提供一套全面的云服务，其中包括计算、存储和网络功能。这些服务支持各种应用，例如 AI 和机器学习、应用程序开发、数据和分析、物联网 (IoT) 以及安全和治理。这些工具可帮助企业推动创新、提高运营效率、增强协作、提高工作效率和降低成本。
    • 个人方面。OneDrive 和 Microsoft 365 等服务提供对文件和应用程序的无缝、高度安全的访问，支持从任何位置高效工作。这些服务还提供了可靠的协作工具，可支持用户轻松共享文档并实时协作。无论是独立工作还是作为团队成员开展工作，此集成都可帮助用户保持高效和连接。

    未来趋势

    云计算的未来趋势

    云仍处于其发展的早期阶段，未来几年我们有望看到其更具创新意义的使用。下面是一些有望塑造云计算的未来的趋势：
     
    • AI 集成。AI 正日益与云计算集成，可帮助企业自动执行任务、从数据中获取见解，并做出更好的决策。这种集成正在推动医疗保健、教育和其他各个领域的发展，最终提升整体生活质量。
    • 边缘计算。边缘计算是一种分布式计算模型，可将处理部署在更靠近网络边缘的位置，支持更快、更高效的数据处理。这增强了自动驾驶车辆、城市基础设施和 IoT 设备等实时应用程序，提高了我们的环境的安全性和响应能力。
    • 量子计算。通过在极短时间内支持处理海量数据，量子计算具有彻底改变云计算的潜力。这可能促成加密、材料科学和复杂系统模拟等领域取得突破性进展。
    云是一种功能强大的工具，可改变人们的生活和工作方式。除了技术进步之外，云还可以通过多种方式继续推动积极社会影响：
     
    • 教育。通过为世界各地的学生提供远程学习机会和资源，而无需考虑其地理位置，云技术提高了教育的可获取性。
    • 医疗保健。通过支持远程医疗、远程监视以及在医疗保健提供方之间高效共享医疗数据，基于云的医疗保健解决方案可帮助改进患者护理。
    • 环境可持续性。云服务提供商日益重视可持续发展，并且许多提供商正致力于实现碳中和甚至碳负排放运营。这种转变有助于减少 IT 运营的总体碳足迹。
    • 经济增长。通过降低初创企业和小型企业的进入门槛，云可以促进创新和经济增长。它提供可缩放的资源，可随企业发展进行调整，从而支持创业和提供就业机会。
    随着云的不断发展，它仍将是推动积极变革的源泉，并帮助应对一些全球最紧迫的挑战。

    常见问题解答

    • 云的主要用途是通过 Internet 提供对计算资源和服务的按需访问。这包括各种服务，例如服务器、存储、数据库、网络、软件、分析和智能。云支持用户和组织使用这些资源，而无需管理物理服务器或在其自己的计算机上运行软件应用程序。
    • 如果要访问云，需要选择云服务提供商，如 Microsoft Azure。然后创建一个帐户，选择所需的服务，然后按照提供商的说明设置和配置服务。配置所有内容后，即可开始使用云服务，包括存储文件、运行应用程序和部署网站。
    • 否，OneDrive 本身不是云。OneDrive 是由 Microsoft 提供的云存储服务。术语“云”是指通过 Internet 存储、管理和处理数据的全球远程服务器网络。OneDrive 是使用此云基础结构为用户提供存储解决方案的众多服务之一。
      详细了解 OneDrive。
    • 否，Azure 本身不是云。Azure 是 Microsoft 提供的公有云平台。“云”描述了通过 Internet 存储、管理和处理数据的全球远程服务器网络。Azure 是作为此更广泛的云基础结构的一部分提供云服务（包括存储、计算和网络）的众多平台之一。
    • 可以通过许多资源来帮助你详细了解云领域的职业。Coursera、Udacity 和领英学习等平台提供在线课程。还可通过招聘门户、专业云计算社区、网络研讨会和会议，以及书籍和博客来深化对该领域的理解。此外，Microsoft Learn 提供自定进度的在线培训，可帮助你了解超过 15 种与云相关的职业。
      探索云领域的职业。
    • 并非所有数据都存储在云中。尽管云存储因其可访问性和可伸缩性而广受欢迎，但一些组织和个人仍出于各种原因（包括安全性、速度和对数据的控制）使用本地存储。此外，一些数据存储在将云存储和本地存储相结合的混合环境中，以平衡这两种方法的优势。存储的选择取决于数据敏感度、成本和性能要求等因素。
    • 否，并非所有数据都会传输到云。尽管云服务广泛用于数据存储和处理，但许多系统和设备仍通过本地存储和处理功能来运行。此外，一些数据是在更靠近其生成和使用位置的边缘处理和存储的，而不是发送到云。使用云存储的决定取决于各种因素，包括应用程序的特定要求以及个人或组织的偏好。
